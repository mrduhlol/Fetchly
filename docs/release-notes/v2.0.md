## Fetchly 2.0

A from-scratch rebuild. v1.8's bundled engine had gone stale and YouTube began refusing it — which surfaced as the generic *"Fetchly couldn't retrieve media information from this link."* v2.0 ships a current on-device engine and names the real cause of every failure.

### Install first

- **Uninstall any older Fetchly (v1.8 or earlier) before installing this one.** These builds are debug-signed; Android refuses to update across different signing keys.
- Android 10 (API 29) or newer. The APK is about 124 MB — it bundles the Python engine and ffmpeg so everything runs on-device.

### Highlights

- **YouTube works again** — video with sound (streams fetched and muxed on-device), Shorts, and audio-only, through yt-dlp 2026.08.19 packaged inside the app
- **Every failure names its real cause** — sign-in demand, private or deleted video, geo-block, rate limit, expired link, full disk, merge failure — instead of one catch-all sentence
- **Downloads screen** — live stage, percent and speed, cancel; history with retry and a details sheet (open, share, delete)
- **Verified saves** — magic bytes and size checked before a download is reported as saved
- **Expired links re-resolve once automatically** (403/410), then fail honestly if the fresh link no longer matches
- **Other platforms are best effort** through the same engine; direct links (mp4/mp3/jpg/…) download as-is
- **No backend, no accounts, no configuration** — resolution, downloading and merging all happen on the phone
