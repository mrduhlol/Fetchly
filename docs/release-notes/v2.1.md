# Fetchly 2.1

This release brings the current interface to the downloadable APK: Apollo branding and splash, gold and white themes, platform selection, media modes, clipboard paste, and batch links.

The launcher artwork now fits within Android's adaptive icon safe area. The README download button uses the stable `fetchly.apk` asset. Releases include the source commit in BUILD.txt and SHA-256 checksums; the release workflow rejects tags that disagree with the APK version and reuses a persistent signing key.

## Installing over 2.0

The previously published 2.0 APK used a different debug signing certificate. Android cannot update that installation with 2.1. Uninstall the old Fetchly first, then install 2.1. Uninstalling clears app settings and in-app history; copy any needed app-private files first. Future builds from this release workflow reuse the 2.1 signing key.
