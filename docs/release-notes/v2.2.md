# Fetchly 2.2

- Larger supported-app icons below the fetch button, with pop-and-shake feedback.
- New gold and ivory backgrounds, full-size media previews, and portrait orientation support.
- App size settings: 80%, 100%, and 120%.
- Improved launcher logo fit and a white icon that applies after the app leaves the foreground.
- Video container buttons and download-size labels in the main and share pickers.
- MP3 audio at 96, 128, 256, and 320 kb/s, retaining available source languages.
- Ongoing background download notifications with a Moai emoji.
- © mrduhlol credits on Home and About; simplified About information.
- Extraction runtime warm-up, cached module loading, and shared overlapping fetch requests.

Validation: 244 JVM tests and 21 Python tests passed; APK build and Android lint passed with warnings. Visual verification of this update and live fetch-speed benchmarking remain outstanding.

## Updating

Install over the published 2.1 APK: this release workflow reuses its persistent signing key. No uninstall is required for that build. The old 2.0 APK used a different signing key; upgrading from it still requires uninstalling, which clears settings and in-app history.
