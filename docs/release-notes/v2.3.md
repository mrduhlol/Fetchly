# Fetchly 2.3

- Removed artificial padding around both launcher logo variants and the share-sheet icon.
- Replaced the small Home footer illustration with one continuous full-height wallpaper in each theme.
- Removed white backgrounds and filled tiles from supported-app marks, retaining their tap animation.
- MP4 and MKV buttons now sit below Video/Audio in both pickers, with MP4 selected by default. MP4 keeps video without re-encoding and converts incompatible audio to AAC.
- Format sizes use reported byte counts or estimates from source bitrate and duration when available. Sources without either still show that the size is unknown.
- Added X bulk ZIP for downloadable multi-media posts, including photo attachments and available video entries. ZIPs save in Downloads/Fetchly; missing or inaccessible source media cannot be included.
- Added Pause beside Cancel, Resume on paused entries, and Pause in the download notification. Eligible direct files retain validated partial data; other sources may restart on Resume.
- Download status-bar icons now use a monochrome Moai while downloading and a sunglasses Moai when completed. Android controls the small icon color; the expanded notification also uses colored artwork.

Uses the same persistent signing key as published 2.1 and 2.2 APKs, so those installations can update in place.

The release pipeline builds the APK and runs JVM tests before publication. Native visual verification remains limited: the test emulator's Android system became unresponsive. Live fetch latency and all platform-specific downloads have not been comprehensively benchmarked.
