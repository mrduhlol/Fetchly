# Fetchly 2.4.1

Includes the pause/resume, frozen grey download cards, thin green Resume control, YouTube sizes, Home readability, new Library art, media-thumbnail notifications, and faster fetch/download startup from 2.4.

The fast download path reuses fetched stream metadata. If the source rejects cached URLs or needs fresh guest cookies, it falls back to resolving the page again. A rejected cached transfer never prevents that refresh.

## Installing

The published v2.3 APK has a different signing certificate. A one-time uninstall is required before installing this release; uninstalling clears settings and in-app history. Back up anything needed first. Partial files already deleted by v2.3 cannot be restored.

This release uses the pinned persistent signer introduced in the corrected v2.4 release. Installations of corrected v2.4 can update in place. Publication is blocked if the APK certificate differs from `docs/SIGNING_CERT_SHA256`.

Verification covers 252 JVM tests, 32 Python tests, lint and APK build. The real-engine transfer test exercises cached startup, retained partial bytes, and HTTP Range resume. Android source response times and scheduling still affect startup. The updated native app reached Home, but device-hub screenshot failures prevented a complete rendered visual check.
