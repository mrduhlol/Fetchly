# Fetchly 2.4.3

Fixes the zoomed installer and share-sheet icon by displaying the supplied PNG directly, without adaptive masking or scaling. Launcher artwork now fits the adaptive icon viewport instead of overflowing it. The original logo asset is unchanged.

Uses the same pinned signing certificate as corrected 2.4, 2.4.1 and 2.4.2, allowing in-place updates from those versions. Published 2.3 still requires one uninstall/reinstall because its signing certificate differs; uninstalling clears settings and in-app history.
