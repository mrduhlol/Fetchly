# Fetchly 2.4.4

- Light mode’s Home footer fades into warm ivory to match the wallpaper, with dark copyright text. Dark mode retains its black fade.
- Fixes a pause/resume scheduling race: Pause now finishes cancelling the previous work before Resume can schedule its replacement. Queue commands finish their history and scheduler updates even when the initiating screen closes. Retained partial files continue to be used where the source supports resuming.
- Removes media thumbnails from download and completion notifications, including the background image request. Small Moai status icons and notification actions remain.

Uses the same pinned signing certificate as corrected 2.4 through 2.4.3, allowing in-place updates. Published 2.3 requires one uninstall/reinstall because its signing certificate differs; uninstalling clears settings and in-app history.
