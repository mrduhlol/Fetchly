# Fetchly 2.4.6

The share activity now explicitly supplies an adaptive logo instead of inheriting the plain application PNG. This addresses extra legacy-icon padding in custom share sheets such as Pinterest, while retaining the complete artwork within the adaptive viewport. The installer still uses the original PNG. Final icon rendering and caching are controlled by the sharing app and Android.

Uses the same pinned signing certificate as corrected 2.4 through 2.4.5, allowing in-place updates. Published 2.3 requires one uninstall/reinstall because its signing certificate differs; uninstalling clears settings and in-app history.
