# Fetchly Lite 2.4.7-lite

Built from the latest source alongside Fetchly 2.4.7, using the existing pinned persistent production certificate and stable package `com.fetchly.app.lite`. Version code 31 supports an in-place update from production 2.4.6-lite.

Includes Home, Downloads and Library; the fixed Greek pottery interface and Hermes branding; automatic link resolution; thumbnail format selection; MP3-only audio quality preferences; individually selectable post attachments where exposed by the extractor; Android share downloads; notification controls; and one download at a time.

Requires Android 10 (API 29)+ and a 64-bit ARM phone. It installs alongside full Fetchly. New development builds use a separate `.test` package and development signer; an older test APK using the stable ID must be removed before installing production Lite.

[Download APK](https://github.com/mrduhlol/Fetchly/releases/latest/download/fetchly-lite.apk) · [Exact size, checksum and build metadata](https://github.com/mrduhlol/Fetchly/releases/latest/download/fetchly-lite-release.json) · [SHA-256](https://github.com/mrduhlol/Fetchly/releases/latest/download/fetchly-lite.sha256).

Release automation runs unit tests, lint and Python bridge tests, then verifies APK package/version, non-debuggable manifest, ARM64 architecture and production signer before publication. Public-site restrictions still apply; see [verification limits](https://github.com/mrduhlol/Fetchly/blob/main/docs/lite/README.md#size-and-verification-limits).
