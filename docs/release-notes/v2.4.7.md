# Fetchly 2.4.7

This release brings the latest implemented interface and download improvements to the stable APK.

## Main app

- Matching day/night Apollo Home artwork with a scrolling monument reveal.
- Inset three-tab navigation dock with a sliding selection underline.
- Appearance palette previews and a dedicated Appearance background.
- Notification on/off controls and the updated Apollo notification mark.
- Media thumbnails in the compact share download dialog.
- Individual post attachment support while preserving full-app quality choices and ZIP retries.

## Production builds

Both editions are built as optimized, non-debuggable release APKs with the existing pinned production signing certificate. Version code 31 allows updates from 2.4.6. Corrected full Fetchly 2.4 and later can update in place; published 2.3 still requires the documented one-time uninstall/reinstall because its certificate differs.
